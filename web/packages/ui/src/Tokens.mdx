# Tokens

The brand is one file: `packages/tokens/brand.json` (name, identity, radii and which palette — A `lakeshore`, B `evergreen`,
C `dusk` in `packages/tokens/palettes/`). Change it → `pnpm --filter @northline/tokens build`; the build fails when a
text pair drops below WCAG AA. The toolbar's paintbrush previews the other palettes. Components use the semantic roles
below, never a ramp step or a colour.

Spacing `--space-0…16` (4px base), type `--text-2xs…5xl` (body 15px), controls `--size-control-sm/-/lg` (32/40/48,
drawn; every target still ≥ 44px), radii `--radius-xs/sm/md/lg/pill`, shadows `--shadow-sm/md/lg/focus`, z-index
`--z-dropdown…toast` and motion `--duration-fast/--duration/--ease` come from `packages/tokens/scale.json` — fixed, not
brand.
