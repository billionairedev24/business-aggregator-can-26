Java 25 · Spring Boot 4.1.1 · modular monolith

One Java platform, event-driven inside and out.

A Spring Modulith application split into bounded modules, fronted by a Spring Authorization Server for OAuth 2.1 / OIDC. State lives in PostgreSQL; search in Elasticsearch; hot state, sessions and live tracking in Redis. Every cross-module change is a domain event persisted in the same transaction and fanned out through Kafka. All data resides in Canada (AWS ca-central-1).

Identity — OAuth 2.1 / OIDC

northline-auth is a Spring Authorization Server (in Spring Security 7) with its own schema. It is the only place passwords, passkeys and second factors are handled. Browsers never hold tokens: each web app talks to a BFF that keeps tokens server-side in a Redis session.
