# AI features

The in-product AI features (Spring AI with OpenRouter) are specified and documented by their own story. This folder is
their place in the documentation site (S-126): every `.md` page added here appears under **AI** in the internal site's
sidebar, and is searchable, without any change to the site.

What belongs here when the features land: the provider and model configuration per environment, data residency and
what leaves Canada, prompts and their review, cost limits, evaluation, and the runbook for turning a feature off.
